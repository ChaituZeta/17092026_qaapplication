# Project Context & Agent Guidelines

This repository hosts the **HP QA Platform (v5)** developed for Zeta Global & HP APJ.

For the comprehensive technical specification, architecture overview, module breakdown, database schema, and server endpoints, refer to [PROJECT_MEMORY.md](file:///c:/Users/ChaithanyaBabuBogine/Downloads/Claude_Projects/hp-qa-platform-v5/PROJECT_MEMORY.md) and [PROJECT_REVIEW.md](file:///c:/Users/ChaithanyaBabuBogine/Downloads/Claude_Projects/hp-qa-platform-v5/PROJECT_REVIEW.md).

## Quick Overview
- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons
- **Backend**: Express in `server.ts` (API routes, proxy engine, nodemailer email dispatcher)
- **Database**: Supabase PostgreSQL (`https://ogklfczlceubykreddib.supabase.co`) with LocalStorage offline fallback
- **QA Standards**: 22 automated & semi-automated checkpoints described in [QA_CHECKPOINTS_GUIDE.md](file:///c:/Users/ChaithanyaBabuBogine/Downloads/Claude_Projects/hp-qa-platform-v5/QA_CHECKPOINTS_GUIDE.md)
